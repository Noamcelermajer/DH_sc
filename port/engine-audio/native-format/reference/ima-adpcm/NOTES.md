# VoxN IMA ADPCM decoding

This milestone decodes the recorded VoxN `Data` payload to interleaved signed
16-bit PCM. It deliberately stops at the codec boundary: state transitions,
segment/cue scheduling, seeking across live transition state, mixing, Android
playback, lifecycle handling, and resource ownership are not connected here.

All 17 cache inputs use the same twelve-byte `Afmt` record:

```text
format tag       0x0011 (Microsoft IMA ADPCM)
channels         2
sample rate      32000 Hz
block alignment  1024 bytes
bits per sample  4
samples/block    1017
```

## Original-library basis

`provenance.json` pins the original ARM32 ELF and the exact byte ranges used.
The native constructor at `0x00886bfc` copies the `Afmt` values, rejects more
than eight channels, and derives samples per block as
`(((block_align - 4 * channels) * 2) / channels) + 1`. The native `DecodeBlock`
at `0x00887068` reads a signed 16-bit predictor and unsigned step index from
each four-byte channel header. It emits the predictors, then consumes four
bytes per channel, low nibble first, updates the IMA predictor/index, clamps
the index to 0..88, and saturates PCM to -32768..32767. The WAV decoder at
`0x008758d8` independently corroborates the same loop. The exact index and
step tables occur in the original ELF at `0x00911a14` and `0x00911a24`.

The port adds bounded-span, output-capacity, complete-group, overlap, and step
index validation. Those checks are safety guards, not claims about the old
ABI. No original code is executed.

## Golden corpus

`golden-output.json` contains only names, sizes, hashes, format facts, and PCM
hashes; it contains no APK/cache audio bytes. The PCM hashes were generated by
wrapping each externally retained `Data` payload in a standard IMA ADPCM WAV
header and decoding with FFmpeg's `adpcm_ima_wav` decoder to `s16le`. The host
gate streams the reconstructed decoder output into SHA-256, compares all 17
full outputs with those goldens, and independently compares the first, middle,
and last block of every file against a small Python reference implementation.

Run with copyrighted inputs outside the repository:

```text
python3 port/engine-audio/native-format/tests/run_ima_adpcm_host.py \
  --cache ABSOLUTE_CACHE_FILES \
  --original-elf ABSOLUTE_ORIGINAL_ELF \
  --compiler /usr/bin/g++ \
  --build-dir /tmp/dh2-voxn-ima-adpcm
```
