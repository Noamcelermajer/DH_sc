Archived build notes and focused checks for the earlier ARM32 compatibility experiment.

This experiment used an ARM64-hosted translation runtime with targeted compatibility fixes. It is separate from the current native source reconstruction and is not a verified playable release. Old APK installation instructions and test packages are not maintained here.

See the [repository README](../../../README.md), the [compatibility archive overview](../../README.md), and [BUILDING.md](../../BUILDING.md). Original game assets and third-party dependencies remain subject to their respective rights and notices.
