# Archived compatibility research

This directory contains an earlier ARM32 compatibility experiment, its source patches, focused validation evidence, and third-party notices. It is historical work and does not describe the current native source reconstruction or a playable release.

The current project overview and supported source-port scope are in the [repository README](../README.md). Rebuild notes for the old experiment remain in [BUILDING.md](BUILDING.md). Original game binaries, assets, and cache files are subject to their rights holders; this archive grants no distribution rights.
