# Legacy Android compatibility work

This directory records an earlier experiment that ran the supplied ARM32 game through an ARM64-hosted translation runtime with targeted fixes. It is kept as historical research; the current project direction is independent source reconstruction. See the [project README](../README.md).

The experiment is not a native ARM64 game port or a complete playable release. Its host and emulator checks apply only to the wrapper components and checkpoints described in their records.
